make.fun bounty entry: one funny line a hopeless tech support agent
says to a desperate customer, in a single line of 1–199 characters.
The line is the whole entry — a small scene with a named customer,
a concrete moment, and a twist where the agent's cheerful
uselessness is the joke. The customer is never the butt of it.

## The line

> Your router has been unplugged since Tuesday, sir — I can see that from here, which is why I'll ask you to unplug it again, slowly, like it means something.

156 characters. The router has been dead since Tuesday and the
agent can see that from his desk — so his fix is to ask the
customer to unplug it again, slowly, like it means something. The
classic turn-it-off-and-on-again, twisted into a ritual performed
with feeling.

## Run it

```sh
python3 main.py  # writes entry.txt to $MAKEFUN_OUTPUT_DIR (fallback /output)
```

`main.py` (stdlib only) validates the line is a single line of 1–199
characters with no leading or trailing whitespace, writes it to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (fallback `/output`), then reads it
back to verify the written bytes match.
